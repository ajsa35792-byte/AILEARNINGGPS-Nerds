# AI Learning GPS

AI Learning GPS - прототип образовательного навигатора для школьников 7-12 классов.

Проект помогает ученику понять, что изучать дальше, если у него есть конкретная учебная цель, но нет понятного плана подготовки.

## Проблема

Школьник может знать свою цель:

- подготовиться к контрольной;
- улучшить результат;
- подготовиться к ЕНТ;
- подготовиться к олимпиаде;

но при этом не всегда понимает:

- с какой темы начать;
- какие пробелы мешают двигаться дальше;
- что изучать в первую очередь;
- как распределить подготовку по времени.

По результатам предварительного опроса школьников:

- 90% не всегда понимают, какую тему изучать следующей;
- 76,7% хотя бы иногда не могут определить, что именно им непонятно;
- 83,3% считают приложение, которое рекомендует следующий шаг, полезным или очень полезным.

## Решение

AI Learning GPS работает по логике навигатора:

**Цель → Диагностика → Результат → Следующий шаг → Маршрут**

Пользователь выбирает учебную цель, проходит короткую диагностику и получает:

- общий результат;
- результат по темам;
- рекомендуемый следующий шаг;
- учебный маршрут.

## Целевая аудитория

Школьники 7-12 классов.

Текущая версия MVP работает только с математикой.

Примеры целей:

- контрольная;
- ЕНТ;
- олимпиада;
- повторение материала.

## Что реализовано в MVP

- выбор учебной цели;
- выбор класса;
- выбор математических тем;
- короткая диагностика из 8 вопросов;
- автоматический подсчет правильных и неправильных ответов;
- общий процент результата;
- результат по отдельным темам;
- определение рекомендуемой следующей темы;
- построение учебного маршрута;
- сохранение прогресса локально в браузере;
- адаптивный интерфейс для мобильных устройств.

## Текущая логика диагностики

В текущей версии используются заранее подготовленные наборы диагностических вопросов.

Диагностика пока не генерируется индивидуально ИИ для каждого пользователя.

## Текущая логика маршрута

Маршрут строится на основе заранее заданной логики тем и результатов диагностики.

В текущем MVP маршруты разных пользователей могут быть похожими.

Полная AI-персонализация маршрута пока не реализована.

## Роль ИИ в развитии проекта

Следующая версия предполагает использование ИИ для:

- анализа учебной цели, написанной пользователем своими словами;
- генерации диагностических вопросов под конкретный класс и цель;
- определения конкретных пробелов в знаниях;
- выбора наиболее полезного следующего шага;
- создания персонального маршрута;
- пересчета маршрута после новых результатов.

Целевая логика продукта:

**Goal → Diagnose → Identify gaps → Next best step → Learn → Measure → Recalculate**

## Технологии

- Bolt
- React
- TypeScript
- localStorage
- база данных / backend-инфраструктура Bolt

## Исследование

Перед созданием MVP был проведен предварительный опрос школьников.

Количество ответов: **30**.

Результаты опроса использовались для проверки самой проблемы и интереса пользователей к идее персонального учебного навигатора.

## Ограничения текущего MVP

- работает только математика;
- диагностические вопросы пока шаблонные;
- полноценная AI-генерация диагностики пока не реализована;
- маршруты пока не полностью персонализированы;
- AI-пересчет маршрута после каждого изменения пока не реализован;
- основной fallback для сохранения прогресса - localStorage браузера.

## Главное отличие идеи

AI Learning GPS задуман не как обычный AI-репетитор, который просто объясняет тему.

Главная идея продукта - определить:

**что именно ученику лучше изучать следующим, чтобы быстрее приблизиться к своей цели.**
